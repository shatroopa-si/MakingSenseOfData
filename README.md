# Making Sense Of Data
This repo contains exercises from the book titled "Making Sense of Data".  
It also contains relevant notes and code segments helpful for data analytics and visualization.  

_PS: The book comes in two volumes._

#### Language: Python v3.10
#### OS: Windows 11
##### Setup virtual environment
```
python3 -m venv venv
.\venv\Scripts\Activate.ps1         # Activate venv

pip install -U pip
pip install matplotlib
pip install numpy
pip install pandas
pip install seaborn
```
